# Changelog

## 0.2.0 — Gospel Groove Lab (2026-10-11)

- Replaced fixed 4-beat playing patterns with a 16-step worship/praise arrangement sequencer.
- Added chord inversions, nearest-note voice leading, extended chords, moving bass notes, arpeggios, syncopated stabs, and simple diatonic fills.
- Added performance energy and melodic fills controls.
- Added a no-microphone **Hear groove** audition button.
- Added a local song/arrangement memory for manually saved key, chord progression, style, tempo, and energy.
- Added optional sampled piano playback using Salamander Grand Piano V3 CC BY 3.0 by Alexander Holm, with built-in synth fallback.
- Preserved original built-in microphone input, Autonomous and Guided modes, Stop all and GitHub → Netlify static deployment.
- Increased PWA cache version to v0.2.0.

**Known limitation:** This still does not accurately identify songs, separate drums/choir, interpret spontaneous chord changes, or learn musical styles from videos. The phrase "gospel" here describes an early rule-based style approximation, not a validated professional Nigerian-gospel accompaniment model.
